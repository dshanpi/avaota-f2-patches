## TF 卡实测

测试卡为 SU08G 7.40 GiB SDHC、FAT32 单分区；未格式化。

1. 新固件启动后自动挂载 `/dev/mmcblk0p1` 到 `/mnt/SDCARD`，读写模式；mdev 守护进程在线。
2. 烧录前已有的 1 MiB 文件在新固件下读回 MD5 一致：`5d7dc0a3f97a685f3c353aa24fc3bfca`。
3. 四轮日志与两张图片写入 TF 卡，`sync` 后图片 MD5 与主机一致。
4. 所有采集结束后安全卸载；保持板子上电，用户实际拔卡、等待约 3 秒后重新插入。
5. 同一 boot ID 的内核日志在 uptime 315.668 秒记录 `card aaaa removed`，
   319.728 秒重新识别 SDHC 卡，随后第一分区自动挂载。未执行手动 mount 或 mdev 扫描代替热插拔。
6. 重新挂载后，两张图片和原 1 MiB 文件的 MD5 全部一致；挂载仍为读写。

两张图片 MD5 分别为 `52e9c0bbca0a3a772723b95f3b58b19a` 和 `0dae60b0c920eddab83238a96550f863`。
只验证上述 FAT32 卡，不代表其他文件系统、多分区或长时间 SD 压力测试通过。
