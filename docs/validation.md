## 收帧与出图

每轮 35 秒，3 个采集缓冲，输出 NV21 2560×1440，存储到 `/tmp`。实际帧率按采集帧 PTS 计算，并用单调时钟交叉核对。

各 NV21 文件为 5,529,600 字节，传输 MD5 校验一致。MIPI 状态为 `0xf (ok)`，配置日志及 ISP debug 信息均命中原厂 OV13850 参数。
白场对照中，新参数相比旧 GC2083 参数明显改善绿偏和噪声。此对照不等同于标准色卡或多光源标定。

测试先由驱动丢弃 3 秒启动帧，再跳过 60 个交付帧统计 PTS。初测在第181个交付帧保存图片；白场复测在第601帧保存，给 AE/AWB 更多收敛时间。
采集工具记录的 `timeouts=6` 包含启动等待，未单独区分稳态超时。仓库中的 `test/` 配置可用于原版 sample_virvi，但原版示例没有这套额外的帧率计数和延迟保存逻辑。

## 原厂参数兼容性

头文件保持原样。以下字段超出当前 SDK 的 `HW_U8` 范围，编译有整数截断告警：

| 字段 | 原厂值 | 当前 SDK 编译后的值 |
|---|---:|---:|
| `awb_light_num` | 519 | 7 |
| `awb_ext_light_num` | 512 | 0 |
| `awb_skin_color_num` | 512 | 0 |

低位值与参数表中条目数量一致，实际运行可收敛白平衡。但高位 `0x200` 的含义仍需原厂确认，不能仅凭出图证明其可以忽略。
本次没有修改公共结构体 ABI，也没有用强制类型转换隐藏告警。

原厂头文件标注 2560×1440@60fps、WDR=0；30fps 共用该配置，没有独立的原厂 30fps 标定文件。
